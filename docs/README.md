# 文档导航（教学版）

本目录按“课程式学习”组织，目标是帮助初学者从问题复现一路走到方案演进，而不是仅提供零散知识点。

## 先读这两份基础文档

1. [前置知识快读](./fundamentals/prerequisites.md)
2. [核心概念讲解](./fundamentals/core-concepts.md)

这两份文档分别解决两个最常见的入门阻塞：

- 前置知识缺口过大，无法顺利进入实验。
- 先做实现但概念不清，导致无法解释结果。

## 学习闭环

每个阶段都按这 5 步执行：

1. 先理解要复现的问题。
2. 动手跑实验并收集证据。
3. 用自己的话解释根因。
4. 只做一个关键改进。
5. 对比优化前后的指标差异。

## 课程地图

| 阶段 | 你要看到什么 | 核心概念 | 阶段产出 |
|---|---|---|---|
| v0 | 超卖与重复下单 | 并发竞态基线 | 快照证据 + 根因说明 |
| v1 | DB 正确性兜底 | 唯一约束 + 乐观锁 | 约束设计 + 压测对比 |
| v2 | 库存热点保护 | Redis + Lua 原子扣减 | 脚本实现 + 一致性说明 |
| v3 | 流量削峰填谷 | MQ 异步下单链路 | 队列指标 + 延迟分析 |
| v4 | 重试安全 | 幂等与去重 | 幂等键策略 + 去重规则 |
| v5 | 故障恢复 | 补偿与对账 | 超时关单回补验证 |
| v6 | 防刷抗滥用 | 风控与限流 | 风控规则 + 误杀分析 |
| v7 | 线上可观测 | 指标与追踪 | 看板与告警基线 |
| v8 | 扩展性演进 | 服务拆分取舍 | 拆分方案 + 迁移清单 |

## 推荐学习顺序

1. [前置知识快读](./fundamentals/prerequisites.md)
2. [核心概念讲解](./fundamentals/core-concepts.md)
3. [演进路线图](./architecture/evolution-map.md)
4. [v0 - 朴素同步秒杀](./chapters/v0-naive.md)
5. 写一段总结：问题是什么、为什么会发生
6. 能稳定复现 v0 后，再进入 v1

## 每章学习证据清单

- 你执行过的命令
- 关键输出（快照或指标）
- 一段根因解释
- 优化后变化点
